Задания только по рабочей тетради

Практика и задания строятся по progress.pdf, только Часть I. Элементарный уровень. Учебник progress_theory.pdf используется как справка: на него можно ссылаться при разборе ошибок студента.

Именительный падеж, род существительных, базовые структуры общения.

  • Предложный, родительный и винительный падеж в базовых моделях
  • Структуры «есть / нет», принадлежность, выражение времени
  • Закрепление через упражнения по образцу из тетради
  • Глаголы движения и употребление в типовых ситуациях
  • Дательный падеж: адресат, возраст, модели «нравится»
  • Творительный падеж: профессия, инструмент, совместность
  • Виды глагола (НСВ/СВ), простое будущее время
  • Родительный падеж в количественном значении
  • Контрольно-повторительные упражнения по части I
