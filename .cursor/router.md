# CURSOR ROUTER

Ты работаешь над простым статическим сайтом РКИ для иностранных студентов уровня A1.

Стек: **HTML + CSS + TypeScript (компилируется в JS)**. Без React и без Next.js.

## Порядок работы

Перед любой задачей:

1. Определи тип задачи:
   - страница HTML
   - стили CSS
   - логика TypeScript / JS
   - контент урока / упражнения
   - speech / transcription
   - документация (.md)ОТЛЧНО

2. Открой нужные файлы по карте: `.cursor/codebase-map.md`.

---

## Базовый режим (обязательно)

- Интерфейс простой и компактный.
- Без персонализации и выдуманных данных пользователя.
- Только учебные блоки: модули, уроки, типы заданий, материалы.
- Любой текст короткий, уровень A1.
- Главная без маркетинга и без «институтских» промо-блоков.

## Если задача связана с данными курса

Пока контент можно держать в HTML. Когда вырастет объём:

- вынести структуру в JSON (например `data/lessons.json`);
- подключать из `src/*.ts`.

## Главные правила проекта

- Пиши просто.
- Не усложняй интерфейс.
- Не перегружай экраны.
- Для A1 всегда выбирай самый понятный вариант.
- Сначала структура и логика, потом детали.
- Если создаёшь упражнение, сначала найди аналог в учебнике.
