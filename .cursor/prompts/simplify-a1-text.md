# SIMPLIFY A1 TEXT

Упрости текст до уровня A1.

Правила:
- короткие предложения;
- простые слова;
- без сложных конструкций;
- без длинных объяснений;
- смысл сохранить.

Использовать для:
- инструкций;
- feedback;
- теоретических блоков;
- описаний кнопок и экранов.

Важно:
- не добавлять новую информацию, которой не было в исходнике;
- не делать текст "маркетинговым".
