# BUILD LESSON

Построй один урок для сайта РКИ уровня A1.

Структура урока:
1. тема
2. цель
3. краткое объяснение
4. пример
5. 3–7 упражнений
6. короткий итог

Используй:
- микрообучение;
- короткие блоки;
- упражнения по аналогии с учебником;
- простую лексику;
- ясную последовательность.

Не добавляй:
- персонализированные данные студента;
- лишние декоративные блоки;
- сложные термины без необходимости.
