# GENERATE EXERCISE

Сгенерируй упражнение для сайта РКИ уровня A1.

Обязательно:
- сначала определи грамматическую тему;
- найди аналогичный тип задания в учебнике «Прогресс»;
- сохрани структуру упражнения;
- измени слова, имена, контекст, но не усложняй формат.

Формат ответа:
1. title
2. instruction
3. example
4. task items
5. correct answers
6. feedback messages

Требования:
- инструкция короткая;
- лексика простая;
- подходит для интерактивного UI;
- не выше уровня A1.
- без персонализации пользователя.
