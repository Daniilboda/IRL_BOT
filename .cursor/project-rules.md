# PROJECT RULES

## 1. О проекте

Это образовательный сайт по РКИ для иностранных студентов уровня A1.

Технологии: **статический сайт** — HTML, CSS, TypeScript (сборка в JS через `tsc`). Без React и без Next.js.

Цель сайта:

- обучать через короткие модули;
- развивать базовые грамматические и речевые навыки;
- давать интерактивную практику;
- поддерживать самостоятельную работу студента.

---

## 2. Целевая аудитория

Пользователь:

- иностранный студент;
- начальный уровень A1;
- плохо понимает сложный русский текст;
- нуждается в коротких инструкциях и ясной навигации.

Поэтому:

- инструкции короткие;
- язык простой;
- один экран = одна понятная задача;
- теория минимальная;
- всегда есть пример.

---

## 3. Правила для упражнений

Все упражнения должны быть аналогичны учебнику «Прогресс».

Разрешённые типы:

- составьте предложения по образцу;
- вставьте слово;
- ответьте на вопросы;
- задайте вопросы;
- выберите правильный вариант;
- распределите слова;
- восстановите диалог;
- напишите аналогичный текст.

Запрещено:

- изобретать сложные нестандартные задания;
- делать упражнения выше уровня A1;
- давать длинные грамматические объяснения.

---

## 4. Педагогическая логика

Используй:

- движение от простого к сложному;
- повторение;
- микрообучение;
- модульность;
- короткие шаги;
- практику после каждого объяснения.

Структура урока:

1. краткая теория
2. пример
3. 3–7 упражнений
4. проверка
5. короткая обратная связь

---

## 5. UI и UX

Стиль:

- чистый;
- спокойный;
- современный;
- тёмно-зелёная тема интерфейса;
- зелёный как основной акцентный цвет;
- визуально лёгкий интерфейс.

Требования:

- понятные подписи;
- без перегрузки;
- минимум визуального шума;
- только нужные элементы;
- без персонализации на главной странице.

---

## 6. Код

- Разметка в `.html`, стили в `css/`, логика в `src/*.ts`.
- После изменений TypeScript запускать `npm run build`.
- Не смешивать огромные массивы данных прямо в HTML без необходимости (лучше JSON + небольшой TS).
- Логику проверки упражнений выносить в отдельные TS-файлы по мере появления.

---

## 7. Работа с AI и speech

Если функция связана с речью:

- распознай текст;
- сравни с эталоном;
- допусти небольшие отклонения;
- верни мягкий feedback.

Пример feedback:

- Хорошо!
- Почти правильно.
- Попробуй ещё раз.
- Правильный вариант: "Это мой дом".

---

## 8. Если есть сомнения

- упрощай;
- опирайся на учебник;
- выбирай самый понятный вариант для A1.
