# Русский A1

Интерактивный курс русского языка как иностранного для студентов уровня A1. Короткие уроки по элементарной части учебника «Прогресс», автопроверка заданий в браузере, практика говорения и клавиатурный тренажёр.

Сайт рассчитан на самостоятельную работу: один экран — одна задача, инструкции короткие, теория минимальная, после каждого блока есть пример и проверка.

## Для кого

Иностранные студенты начального уровня. Интерфейс и формулировки заданий рассчитаны на человека, который ещё плохо читает сложный русский текст.

## Что уже работает

- **Модуль 1, уроки 1–5.** Именительный падеж, притяжательные местоимения, «Меня зовут…», «У меня есть…», настоящее время глаголов I спряжения.
- **Упражнения в формате рабочей тетради.** Составить предложение по образцу, выбрать форму, вставить слово, ответить на вопрос, написать вопрос, самодиктант.
- **Автопроверка.** Ответ сверяется с допустимыми вариантами, поле подсвечивается, в конце урока считается итог.
- **Говорение.** Студент произносит фразу, браузер распознаёт речь (Web Speech API) и сравнивает её с эталоном, допуская небольшие отклонения.
- **Клавиатурный тренажёр.** Русская и английская раскладки, таймер, скорость, точность и число символов.
- **Материалы.** Учебник и тетрадь «Прогресс» открываются и скачиваются со страницы курса.

Урок 6 и модули 2–4 размечены в программе курса и пока не открыты для прохождения.

## Программа курса

| Модуль | Тема | Статус |
| --- | --- | --- |
| 1 (A), уроки 1–5 | Именительный падеж, род, базовые фразы и диалоги, настоящее время | доступно |
| 1 (A), урок 6 | продолжение модуля | в разработке |
| 2 (B), уроки 7–10 | предложный, родительный и винительный падеж | в программе |
| 3 (C), уроки 11–13 | глаголы движения, дательный и творительный падеж | в программе |
| 4 (D), уроки 14–16 | виды глагола, будущее время, повторение | в программе |

## Стек

HTML, CSS, TypeScript. TypeScript собирается в JavaScript командой `tsc`. Серверной части нет: проверка ответов и тренажёр работают в браузере.

## Запуск

```bash
npm install
npm run build
npm run serve
```

Сайт открывается по адресу `http://localhost:3000`. Статический сервер нужен, чтобы корректно открывались ссылки на PDF.

Главная страница: `index.html`.
