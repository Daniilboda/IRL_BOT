# TEXTBOOK PATTERNS

Основные паттерны упражнений по учебнику:

1. составьте предложения по образцу
2. ответьте на вопросы
3. напишите вопросы
4. распределите слова по группам
5. вставьте нужную форму
6. восстановите диалог
7. напишите аналогичный текст
8. выберите нужную форму
9. самодиктант
10. работа с местоимениями и простыми грамматическими моделями

Главное:
не менять тип упражнения, а адаптировать содержание.

Связка с сайтом:
- аудирование: прослушивание + выбор ответа;
- говорение: произнести фразу + мягкий feedback;
- чтение: короткий текст + вопросы;
- другие задания: вставьте слово, восстановите диалог, выберите форму.
